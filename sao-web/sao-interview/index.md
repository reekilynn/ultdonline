# 第三届SAO系列人气投票　结果公布

## 前言

大家好，我是九里。感谢大家投出的总计667票！

首先，请允许我说明一下，为什么会采用「提问形式」这种奇怪的方式进行投票。SAO系列的人气投票已经办到第三届，但现状是并没有增加多少新角色，所以我担心排名大概会和第一、第二届没有太大变化。于是我就想，如果改为征集问题……主角级角色已经有很多信息，反而可能让不明点更多的配角也获得票数。

然而结果……正如大家所见（笑）。我深切体会到，主角们身上也还有很多不明之处。工作量大约是预想的十倍（汗），但我让他们尽量回答了能回答的问题，希望大家看得开心。
