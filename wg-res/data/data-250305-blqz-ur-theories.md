# 针对UR的一些猜测

作者：别离千载

关于UR，目前已知的内容如下：

1. UR的设计理念是“过剩”，一切东西都是过剩的，核心目的就是将玩家置于一个超出常识的世界和环境中，挑战玩家的常识和自我边界。
2. UR游戏的最终目的是“夺宝”；而通过“夺宝”这一过程想要达成的目的仍旧不明。
3. 文中多次提到了游戏世界和现实世界的交融。
4. AW中存在着超越现实物理法则的设计：加速点数。其规则近乎于按照自身意志改写自己的现象。《恶魔纹章》中的主角同样使用着被自己称为“二动”的特殊能力。
5. 川原想要把UR和AW世界观彻底融合起来。

基于条件1，UR设计的过剩理念就是为了将玩家置身于“常识”所不能处理的世界中。

在这个意图打破玩家世界观的环境下，玩家想要克服身边的困境，需要超越“常识”的力量。而这一超越常识的力量，则是sao和aw中老生常谈的“心意系统”。

结合条件2，UR游戏的核心是“夺宝”；而玩家为了“夺宝”做出的努力则是促使玩家不断激发出超越“常识”力量的过程。

考虑到条件3，文本中多次提及游戏世界和现实世界的交融，如果UR的诞生也是为了这一目的存在，那么可能想要达成的目的则是让游戏内超越常识的力量在现实中也同样能够实现，也就是“在现实中也能拥有改写自身现象的力量”。

而实际上“在现实中也能拥有改写自身现象的力量”实际上早已存在：条件4中提到的加速世界中的加速点数。

考虑到UW中心意系统是“仅在虚拟世界条件下成立的的符合现实世界物理法则的规则”，而AW中通过消耗加速点数可以实现这一行为，可以做出推测：UR游戏作为试验台，最终的目的就是为了在现实中实现“按照自身意志改写现实中自身的规则”。其最终成果则是AW中的加速点数系统。可能这也是川原想要设计的将UR和AW连接起来的最终要素：让心意技术不仅限于网络层面，更进一步延伸到现实层面。

由此基础看，AW所谓的扩张现实系统实际上更像是一个让使用者能够“超越物理法则改写自身现象”的外接器官。通过消耗加速点数实现改写自身现象。

而换个角度来看，心意系统实际上就是物理法则——而所有的物理法则，终归是要实用化的。目前唯一存在的实用化心意系统，就是加速世界中的加速点数。基于此，很难不去猜想UR的最终目的：心意系统现实实用化的过程。
