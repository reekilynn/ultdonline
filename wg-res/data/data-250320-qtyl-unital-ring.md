# Unital Ring杂谈

作者：倾听雨落

艾恩索菲亚Ain Sophia，这个名词出现于Full Dive活动中，在2026年10月7日桐人的生日会后，桐人和亚丝娜做了一个梦，两人出现在某个未知虚拟世界的庭院里，两人在这里见到了已故的优纪和优吉欧。

四人交谈之后，结衣突然出现，她告诉四人，不是梦也不是现实世界，目前所在之处，是所有摇光聚集的地方，结衣将其称为Ain Sophia。

艾恩葛朗特Aincrad，在SAO事件前茅场晶彦称其为具现化的世界【An INCarnating RADius】，然而现在来看，Aincrad应该拆分为Ain和cradle，Ain出自卡巴拉思想，代表无，cradle则是摇篮，寓意着虚无的摇篮。

Aincrad如果代表了虚无的摇篮，那Ain Sophia又要如何理解？

Ain Sophia可以拆分为Ain Soph和Sophia，无限与智慧，也就是一切摇光聚集之地。

根据卡巴拉思想，Ain中诞生Ain Soph，Ain Soph诞生Ain Soph Aur，Ain Sophia与Ain Soph Aur相似，可以将Ain Sophia近似理解为无限光的智慧，这个光自然就是摇光。

这个地方为什么会存在？这个地方在哪里？桐亚为什么出现在这个地方？

在SAO的故事中，见到已故之人已经不是什么罕见的事情了。早在圈内事件，桐亚就曾见到过金苹果公会会长葛林瑟鲁妲。The day after中，亚丝娜见到了幸。Alicization篇，优吉欧死后仍出现过两次。

The day after中，结衣说过玩家出现了极其强烈的感情，cardinal系统检测到后，会将这部分感情记录为档案，其档案就会跟地形或者道具相连结并且保存下来，也可以说是复制了玩家的部分灵魂。所以亚丝娜才能见到幸，将她的想法传递给桐人。

优纪和优吉欧出现在艾恩索菲亚的原因同理可得，都是因为死前出现了强烈的感情，因此灵魂碎片被系统保留下来。

保留了优纪和优吉欧的感情的系统有些差别，一个是与SAO相同的完整的cardinal系统，一个是将cardinal系统简化后的the seed，但结果是相同的，由此可以得出the seed同样有着记录玩家感情的功能。

这些灵魂碎片为什么会出现在艾恩索菲亚？这恐怕是因为艾恩索菲亚就存在于the seed中，这个地方或者说原型至少从SAO时期就已经存在了，所以幸的感情才能保留到ALO的浮游城里。

那么桐亚为什么会出现在艾恩索菲亚？从活动的表演来看，艾恩索菲亚的结衣明显更成熟，假定这是未来的结衣，那么这件事本质上就是过去与未来的连接，此事在AW联动短篇Versus中亦有记载。

Versus中，桐人在使用STL试验机时，意外连接到了未来的BRAIN BURST世界，与2047年的Silver Crow进行了战斗。

虽然作中的解释是量子电脑有干涉平行世界的可能性，不过这确实是能够证明STL能连接过去与未来的有力证据。

参考Versus，桐亚前往的应该是未来的艾恩索菲亚。

如果参考AW，艾恩索菲亚所在的the seed很可能就是放置着所有BB使用者所有资料的中央服务器主视觉化引擎（メイン・ビジュアライザー，Main Visualizer）。

AW中，日本为了维护公共安全，而在全国各地包括公私立学校在内的所有公共场所，都到处设置了公共安全摄影机，拍摄的影像资料全部集中到日本某地、位置绝对保密的“公共安全监视中心（ソーシャル・セキュリティ・サーベイランス・センター，Social Security Surveillance Center）”（简称：SSSC）进行资料的分析处理，过滤追踪所有犯罪征兆和安全隐忧等。有别于一般的全球网络，公共安全摄影机系统使用高速的公共摄影机网络连接，然而号称绝对安全的公共摄影机网络系统却遭到Brain Burst入侵，成为建立对战空间的数据库，连从日本输入了公共安全摄影机技术的宇宙电梯赫密斯之索也成为加速世界游戏中的对战空间。

如果BB的中央服务器本体就在公共安全监视中心，那BB能够控制公共摄影机网络系统也就不奇怪了。

而在心理测量者中，未来的日本社会建立一套西比拉先知系统（Sibyl System/シビュラシステム）── 一个强大的心灵指数监测网络──以声像扫描主动监控市民的心智与精神状态，其测量数据被称作“心灵指数”（Psycho-Pass/サイコパス）。

西比拉系统的本质就是将多个大脑连接在一起进行演算，如果将这些大脑换为摇光，如果将艾恩索菲亚的所有摇光连接在一起，是不是能成为更强的犯罪监视系统，那有没有可能这个系统就是AW的公共摄影机网络系统。

如果猜测成立，那黑雪姬使用的SSS Order很可能就是the seed的一部分控制权限。

SSS Order在SAO28卷中同样出场，全称Supreme System Supervisor Order最高系统管理指令，如果说这是cardinal系统的一部分控制权限，那很可能是星王使用了Administrator和Cardinal都曾使用过的「System call。Inspect command list」，研究了underworld所有的系统指令，得到的产物。

星王虽然在UR篇只在21卷出场过一次，但以星王为underworld而战的理念来看，他应该做了一些事情。

首先，爱丽丝收到的能够再次进入underworld的服务器地址，应该是星王发出的。24卷，菊冈说有人将自己的账号转移到了underworld，根据入侵者数量这里其实有两种情况。

第一种情况，入侵者只有28卷的穆塔希娜。第二种，除了穆塔希娜还有星王，星王使用了SAO的账号进入了underworld。

首先是穆塔希娜，她的来历很可能是旧SAO服务器，是玩家负面感情的集合体，有可能是mhcp。

根据EVA进行解读的话，玩家们的恶意对应的是亚当。

24卷所说：“SAO中滋生的黑暗，已经在广大The SEED连结体中散播、增殖。然后现在，无数的世界重新聚合为一。在这个Unital Ring世界中，黑暗会再度凝聚，待突破压力界限时，就会有新的东西…恐怕是更加深邃、更加黑暗的东西诞生。我仅仅是想看看罢了。”

现在看来，穆塔希娜很可能是想借助UR的竞争机制，引发玩家们更大规模的恶意出现，吸收恶意完成进化。

川原曾经发过推特说明UR与尤娜的人工智能的程序存在关联，以这种视角重新看待序列之争的剧情，不难得出重村教授想要复活悠那所使用的收集感情和记忆的程序与the seed相同。

而KAMURA可能通过重村教授的研究或者在他之前发现了这件事，不仅从旧SAO服务器中找到了穆塔希娜，而且还制作了一款入不敷出的VR游戏。

穆塔希娜的法杖和魔法不祥者的绞轮，应该就是通过这个游戏制作的，为了不受将账号转移到UR后无法使用高级武器的影响，故意将法杖做成了作为低级武器却能使用某种魔法最上位技能的效果。

穆塔希娜获得进入underworld的服务器地址有两种情况，第一种是从结衣处获取，第二种是从星王处获取。第一种情况不作讨论，主要讨论第二种。

想要知道为什么星王会将服务器地址告诉穆塔希娜，就要先想清楚星王的立场问题。

星王很可能因为underworld人很难成为ALICE，而选择了直接制造ALICE或者说是ALICE的碎片，艾欧莱茵很可能就是这个计划的产物，而且可能不止一个艾欧莱茵或者是身体。

灵魂需要载体，那承载着ALICE碎片的载体，也就是艾欧莱茵的身体又是什么？

月之摇篮篇，皇帝一方使用的是以米尼翁为材料制作的身体，而艾欧莱茵自己说过，眼睛周围的皮肤无法承受索尔斯之光，所以才带上了面具，然而米尼翁作为暗黑界黑暗术士制作的产物，最大的弱点就是光。

27卷提到，米尼翁的血液有毒，用光素可以解除，所以这里可以合理推测，艾欧莱茵的身体很可能是星王获得了皇帝一方的技术，并进行了改良，最后只有眼睛周围的部分会被索尔斯之光造成伤害。

然而艾欧莱茵的出现并不能保证underworld的延续，因为underworld人很难成为ALICE这件事并没有解决，这很可能是星王将服务器地址告诉穆塔希娜的原因。

目前underworld所有的ALICE，除了优吉欧和爱丽丝，都是在异界战争中出现的，在争斗中数据会大幅度增长，所以27卷皇帝阿格马尔·威斯达尔斯六世的出现，很可能得到了再次进入underworld的星王的帮助，从而获得了整合骑士团被封印在中央大教堂99层的秘密。

当然皇帝并不清楚是星王的存在，星王应该是将这些情报告诉了穆塔希娜，由穆塔希娜与皇帝合作，并将这些事情进行告知，这也能解释为什么穆塔希娜明明出自旧SAO服务器，却能伪装成underworld的皇室后裔。

星王的计划应该是借助皇帝一方挑起战争，尽可能出现更多的ALICE，在这场战争中死去的underworld人会进入艾恩索菲亚，成为the seed的养料。

之所以和穆塔希娜合作，是想将underworld连接到UR，将underworld人转移到UR中，UR的出现，星王至少是其中一个推手。

当然，星王的本意应该不想挑起战争，但正如12卷Cardinal所说：“你总有一天也会知道放弃时的痛苦……到时候就不是尽力而无法成功……而是得接受自己应该无法成功的推测……”现在失去了星王妃的星王，恐怕已经决定为了underworld的延续，主动放弃某些东西了。

21卷茅场在与星王的谈话中，已经将the seed的未来交给了世界本身的意志，以及其中的居民们来选择，世界的意志自然是the seed，居民则是各个世界的ai。

现在的UR与茅场所预料的统一阶段出现了差别，主要原因应该是与穆塔希娜和星王有关，穆塔希娜希望玩家们的恶意汇聚，星王希望将underworld人转移到UR，目前双方的合作还能进行，但以后就不好说了。

UR的出现应该是the seed自行生成的，只是受到了干扰才变成现在这种强制融合的情况。

Administrator将cardinal系统的主程序烙印在自己的摇光上，获得了系统权限，而cardinal系统的副程序也因此获得了Administrator的灵魂，获得了智慧。同理可得，如果将艾恩索菲亚的所有摇光连在一起，那么the seed是否能获得一定的智慧？

在ALO事件到UR事件前，the seed收集了一年半的数据，艾恩索菲亚也聚集了很多的灵魂碎片，但这有太多的重复，现在的数据已经不足以支持the seed继续进化了，the seed在渴求更多更强烈的感情，所以UR出现了。

UR的主题是生存，这与SAO相近，无论是死亡后账号注销还是最先抵达极光指示之地者将能获得一切的设定，都只是为了让玩家进行竞争，引发出更强烈的感情。

穆塔希娜想要获取感情中带有恶意的部分，星王则是想让玩家适应UR中拥有一定智慧和社会关系的NPC，从而更进一步适应underworld人。

UR的地图名为尤尼艾尔，这与艾恩葛朗特创世纪中的大陆名称相同，这不是巧合，其他融入UR的游戏没有任何要素留下，只有浮游城留在了地图上，这是因为艾恩葛朗特本身就是UR的重要组成部分。

然而艾恩葛朗特可能只是提供了部分基础设定，因为UR地图的大小与underworld人界相同，但750km的大小实在难以成为大陆，而且蛋糕塔一样的构造，理论上也不支持发生艾恩葛朗特创世纪中席卷整个大陆的大战。

到达极光之地能获得什么？如果参考人界的地图，很有可能是the seed的系统控制台，最先抵达的玩家将获得the seed的控制权限。

总结一下，UR的设定里，尤尼艾尔曾经发生了大地切断，各个圆盘堆叠在一起，形成了艾恩葛朗特，各个种族的文明衰退，也失去了圣大树的庇佑和魔法。很久以后艾恩葛朗特坠落，维持着浮游城浮空由两位巫女用生命形成的魔法石也碎裂开，形成了UR中的魔晶石，食用魔晶石就能用出魔法，玩家们也在这个时候进入这个世界，开始与这个世界的居民发生碰撞、融合、战斗。
