# 关于SAO&AW的一点全新构想

作者：SAWAHIRO

在今天加速世界24卷发售后（下称AW24），在简单的速读之后，和熟悉并参与众多川原作品翻译的rkl大佬进行了一番交流，然后又得出来了一些新的猜想，有我的，也有rkl大佬的，在这里进行一个简单的整理。

> 以下内容请在阅读过刀剑神域至21卷，加速世界至23卷并接触或愿意接触24卷剧透的朋友阅读，并涉及川原砾撰写的《加速VS刀剑 千年的黄昏》游戏剧本剧情，内容基于两个故事共通世界线为前提。

AW24卷提到，时至2047年，人工灵魂的自我纠错能力仍然不够完善，换言之，对于负面思路会出现自我放大，这既适用于人工FL，也适用于Topdown型AI。关于高智能人工AI，因为2020年代后期的某个AI事件作为奇迹，全世界对于AI智能性进行了强化管控，缔结了国际协约，相关详细内容全部被加密。这个事件则可能是SAO18卷结尾所说的知性智能间的战争。

提到topdown型AI，我们避不开SAO中的一个重要角色，结衣。而且在SAO最新的21卷之中，结衣在ur世界中被直接变成了有hp条的普通玩家账号状态。但是结衣作为cardinal的子程序，也有主副两个系统，这也就意味着，实际在ur中的只是结衣的主程序。以SAO的ur篇作为衔接AW的剧情发展来猜想，结衣接下来的处境必然不乐观。cardinal system的副程序功能是修正主程序的错误，如果结衣在ur之中的主程序受损，或者说被破坏，那副程序会如何？

川原在SAO11卷中把admin和cardinal的关系形容为双子姐妹，但是cardinal作为admin的第二人格觉醒之后，同样无力修改admin自己的fl，最后cardinal这一人格选择了自杀。

如果将这个关系带入ur之中的结衣，若是主程序被毁，副程序失去了纠错对象，那么这个副程序第二人格产生自我意识后，就会不断累积「主程序的失误导致了ur的最终结果（就如前面提到的AI技术被全面管制）」这一想法，由此产生「想要消灭这些AI（如果ur事件导致桐人亚丝娜失去人身自由的话更是如此）」的想法也是可以预见的。

这一猜想的主要来源旁证，可以用川原撰写的游戏《加速世界VS刀剑神域 千年的黄昏》剧情来说明。千年的黄昏游戏剧情boss就是千年之后的结衣，她因为自己是高智能人工AI，不老不死，在程序世界之中独自生活千年，越发觉得孤独，最终导致她想自我毁灭。但她的程序设定却不允许她这么做，伪了彻底毁灭自己，同时毁掉自己曾经的功绩（所有有名的虚拟世界的建立都和结衣有关），同时让桐亚和其他伙伴们彻底忘掉自己，她利用了心意的力量穿越回了过去，目的是彻底消灭过去的自己，并利用AW的世界去侵蚀ALO，彻底毁掉过去的自己留下的痕迹。而且在游戏中，还提到了未来的结衣被灾祸之铠附身，成为了第七代Chrome Disaster……

可以说，川原在《千年的黄昏》剧本中，让结衣这个人工智能AI成为了整个剧情的中心，所有的故事都围绕着她推进。

另外据考证，2012年，AW动画化时，HIMA在动画官网贴出来了一张在当时看来很突兀的一张图，其中的角色是结衣一个从未出现过的造型，当然那张图早已下架了，不过在一番搜寻后，还是找到了备份图。

那么，HIMA为什么要在2012年，一个全部剧情都和vr游戏及人工智能都还扯不上关系的动画贺图中画一个结衣呢？

在多角度的思考人工智能以及多方位关键上结衣这个角色的情况下，我们进行了更大胆的猜想。

如果以ur篇结衣主程序系统的损毁作为猜想推进下去，再联想川原把admin和cardinal的关系形容为双子姐妹，我们回到AW的剧情中。AW之中的双子姐妹关系，我们能最直接想到的是两个人，黑雪姬和白雪姬两姐妹。如果说ur之中的结衣损毁后还有碎片产生的话，是不是可以联想到结衣在SAO剧情初出场那次，被系统发现异常后桐人做了什么？SAO在uw篇便提出了人工fl，拉斯通过婴儿的空白fl进行培育。如果说结衣出现了损毁碎片，桐人他们用空白fl融合碎片以达到复活结衣的目的，也不是不可能，毕竟拉斯的行为最后桐人他们也算默认了，如果说为了复活最爱的女儿结衣，我想他们应该也不会不同意。而且把topdown型AI的算法变成人工fl中的逻辑思路，其实比反过来要更为简单。而这个复活结衣的人工fl，联想到黑雪姬在23卷的身世自白和那个与亚丝娜同一天的生日，有可能黑雪姬就是使用了结衣碎片的人工婴儿。而我们已知黑雪姬是黑王，她姐姐白雪姬是白王，这场姐妹的战斗，就如同admin和cardinal这对被称为双子姐妹关系的主副程序一样，在大教堂之顶，姐妹相争，到了AW的剧情，仿佛一切重演……

结合川原说过的非血缘关系和灵魂层面关系这一层比较抽象的人物关系，白雪姬这位姐姐的更多情报我们也无法确定，只能等待剧情的进一步推进。

从对于川原在AW动画贺图和游戏剧本几个方面对于结衣的特别凸显，还有AW24卷对于人工智能这一话题的情报展开，结衣这一角色越发的让人觉得是关联两个剧情的关键了……

另外在很久之前我也发过另一篇猜想文，分析了SAO21卷老鼠阿尔戈的上线对于未来剧情的助推可能性……现在我依然保持着我自己当初这个猜想……
